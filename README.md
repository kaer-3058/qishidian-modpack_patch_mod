## 起始点整合包的mod形式的补丁

适用于1.21.1的整合包

使用AI辅助编写的，新时代 vibe coding 的产物

**healthcap-source**：去除原版的血量上限，可以让血量上限提升到1600万。

**wadjetfix**：灾变补丁。修复了灾变里的小Boss-瓦吉特的渲染计算错误导致的游戏进程卡死。

**sablefix**：sable补丁。

​	1.修复sable的一个固有bug。

​	2.修复了sable 2.0.6的固有bug，服务端在发来"忘记区块包"时，本来已经cancel()了，却又抛异常。

**tastejournalfix**：味蕾乐事补丁。修复了味蕾乐事导致的合成物品无法堆叠的问题。

**aircraftdupefix**：沉浸式飞行补丁。修复"沉浸式飞机"里的"战斗飞艇"的bug，玩家坐着飞艇退出重进会复制飞艇。在服务器里可复现。

**bossbucketfix**：技能专精补丁。修复了技能专精的"剑术"技能导致的玩家打灾变Boss没有伤害的问题。

**voidscapefix**：虚空工艺补丁。修复了虚空工艺的网络请求（拉赞助名单、访问更新网站）造成的游戏进程卡死。

**entitysectionfix**：sable补丁。修复了sable迭代实体区块段时被某个 mod 的实体传送踩中（Sable 主嫌、车万女仆次嫌）导致服务端闪退的问题。

**createpkgfix**：机械动力补丁。修复了用匠魂武器左键打机械动力的快递包裹会自我递归导致存档进不去的问题。

**tacznofire**：让TACZ原版枪械开不出火。
